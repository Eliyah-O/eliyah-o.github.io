Настройка подключения — один раз на каждом устройстве

Токен хранится ТОЛЬКО в вашем браузере (localStorage) и никогда не попадает в репозиторий. На чужом компьютере не сохраняйте — нажмите «Забыть токен» после работы.

    Как это работает и что нужно настроить

    Как пользоваться: в блоке 1 отправляете задание — текст, фото, PDF. В блоке 2 забираете готовый результат.

    Запрос обрабатывается в отделе продаж, поэтому результат появляется не мгновенно: после отправки задания нужно подождать, прежде чем нажимать кнопку «Получить предложение».

    Ограничение по файлам: примерно 25 МБ на файл (ограничение GitHub).

    Страница статическая — сама она ничего не хранит. Хранилище — приватный репозиторий GitHub: задания складываются в tasks/, результаты Claude кладёт в results/. Страница обращается к GitHub API вашим токеном, который лежит только в вашем браузере.

    Что нужно сделать один раз:
    1. Создать приватный репозиторий (например vitaprom-inbox).
    2. Положить в него этот файл как index.html и включить GitHub Pages (Settings → Pages → ветка main).
    3. Создать токен: Settings → Developer settings → Personal access tokens → Fine-grained → доступ только к этому репозиторию, право Contents: Read and write.
    4. Открыть страницу, вставить логин, имя репозитория и токен, нажать «Проверить связь».

    Важно: сама страница будет доступна по ссылке всем, кто её знает, но без токена она бесполезна — никаких данных в ней нет. Все данные лежат в приватном репозитории.
