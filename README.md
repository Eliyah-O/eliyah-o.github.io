# eliyah-o.github.io

Корень домена GitHub Pages. Нужен ровно для одного: чтобы браузеры (в первую очередь
Safari, который кэширует иконку НА ДОМЕН, а не на страницу) находили `favicon.ico`
по адресу `https://eliyah-o.github.io/favicon.ico`.

Содержимое намеренно минимальное — только файлы иконок. Страницы (`index.html`) здесь
нет: корень домена отдаёт 404, никакой информации наружу не публикуется.

Сами рабочие страницы живут в отдельных репозиториях, напр. `commercial_offers_page`.
